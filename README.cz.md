## 👨‍💻 O mně
Bývalý elektrikář přecházející do světa **Linuxové správy a DevOps**.
Léta strávená v elektroinstalacích mě naučila striktní inženýrské disciplíně: **dvakrát měř, jednou řež, systematicky izoluj závady a k `rm -rf` přistupuj se stejným respektem jako k 400V pod napětím.**

Moje specializace je **Extrémní Optimalizace & Práce s omezenými zdroji**: provozování lokálních LLM modelů, Docker kontejnerů a MCP serverů na recyklovaném starším hardwaru, kde hraje roli každý megabyte RAM.
